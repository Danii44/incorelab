URBAN NOISE — Streetwear x Web3 (Demo Website)
================================================

In the style of the Urban Noise screenshot you sent: black + purple,
bold type, "Own the noise. Wear the status." hero, and PNG product cards.

HOW TO OPEN (no setup needed):
  1. Unzip this folder
  2. Open index.html in any browser (double-click it)
  3. That's it — no server, no install, no build step
  (Keep the images/ folder next to index.html, or the PNGs won't load.)

WHAT'S INSIDE:
  - index.html : the whole site (HTML + CSS + small JavaScript in one file)
  - images/hero-mascot.png : original mascot character in black
    streetwear with headphones, purple glow
  - images/product-tee.png : Noise Tee, $99
  - images/product-hoodie.png : Genesis Hoodie, $249
  - images/product-sneakers.png : Genesis Sneakers, $499
  - images/product-jacket.png : Noise Jacket (no price set yet)
  - images/product-cargo.png : Noise Cargo (no price set yet)
  - images/product-puffer.png : Noise Puffer (no price set yet)
  - Hero, "Built to make an impact" section, Drop / 001 product strip,
    "Physical by design. Digital by nature." banner, how-it-works steps,
    NOISE Club section, newsletter form, demo cart and demo
    wallet-connect / presale popup

SAMPLE CONTENT:
  All product names, prices and collectibles are samples. The mascot
  and product PNGs are original AI images made for this demo — they
  are not the original Behance artwork. Replace names, prices and
  images with your real collection before using it for a real store.

  Checkout, wallet connection and NFT claiming are front-end demos
  only — they show how the flow would work, they do not process
  payments or real wallets.

EDITING:
  Open index.html in any text editor, change the text, prices and
  image paths, save, and refresh the browser.
